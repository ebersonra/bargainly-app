Teste do Menu Mobile

Clique no botão do menu (três linhas) no canto superior direito para testar

Instruções para teste

  1. Abra as ferramentas de desenvolvedor (F12)
  2. Ative o modo responsivo ou redimensione a janela para menos de 1024px
  3. Clique no botão do menu (três linhas)
  4. O menu deve abrir em tela cheia
  5. Clique novamente no botão do menu para fechar
  6. Ou clique em qualquer link do menu
  7. Ou clique fora do menu

Verifique o console para logs de debug.
